## 为什么日本 VPS 打不开 TVer：锅在 IP 类型

先说结论：TVer 屏蔽的是数据中心 IP 网段，大部分便宜日本 VPS 恰好就是这种 IP。

TVer 本身并不复杂。它由日本电视台、朝日电视台、TBS、东京电视台、富士电视台五家商业台联合运营，日剧、综艺、动画在播出后 7 天内基本都能免费看，广告支撑运营，不需要注册账号。限制就一条：日本境内的 IP 才能播放，来自其他地区的请求在加载页面时就会被拦下，播放页直接锁死。

技术上，这层判定主要发生在 Brightcove——TVer 背后的视频服务商——的鉴权环节。判断逻辑也好理解：真实的日本观众不会从商业机房的地址上网，所以主流数据中心网段被整体列入了屏蔽列表。你那台 VPS 再快、延迟再低，IP 归属是机房，就直接被拒。

能通过验证的只有两种：

- **日本原生 IP（Native IP）**：从日本本土 ISP 申请的地址段，不属于数据中心网段
- **日本 ISP 住宅 IP（Residential IP）**：住宅宽带地址段，解锁率最高，也是养号类业务偏爱的类型

也就是说，黑屏和 VPS 性能、带宽都没关系。换一台原生 IP 的机器，问题当场消失。

1. **验证 IP 归属**。SSH 登录后执行 `curl ipinfo.io`，确认 `country` 是 `JP`，`org` 字段显示的是日本本土 ISP 名称、不含机房机构。这一步 30 秒，能避免后面所有白折腾。
